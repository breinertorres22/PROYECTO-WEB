# PROYECTO-WEB
La pàgina web del projecte TechCare ha estat desenvolupada i gestionada mitjançant un repositori GitHub, utilitzat per emmagatzemar el codi font i controlar les diferents versions del projecte durant el seu desenvolupament.

La web està orientada principalment a la venda i visualització de videojocs, oferint una plataforma online on els usuaris poden consultar diferents productes, navegar entre categories i visualitzar informació relacionada amb cada videojoc.

L’objectiu principal de la pàgina és ampliar els serveis digitals de TechCare, incorporant una part comercial i visual dins del projecte. D’aquesta manera, la web no només representa una eina informativa, sinó també una possible plataforma de venda online relacionada amb el sector tecnològic i dels videojocs.

El repositori inclou tots els fitxers necessaris per al funcionament de la pàgina web, com ara:

Estructura HTML de les diferents pàgines.
Fulls d’estil CSS per al disseny visual.
Scripts JavaScript utilitzats per afegir funcionalitats interactives.
Imatges, logotips i recursos multimèdia utilitzats a la web.
Organització de carpetes i arxius del projecte.

L’ús de GitHub ha permès mantenir una millor organització del desenvolupament, facilitant el control de versions, la modificació del codi i l’emmagatzematge segur del projecte.

A més, aquesta eina és molt utilitzada en entorns professionals de desenvolupament web, ja que permet gestionar projectes de manera més eficient i estructurada.
