# Instrucciones para Añadir Imágenes a las Páginas de Juegos

## Estructura de Carpeta Requerida

Crea una carpeta `img/games/` dentro de tu directorio `img/` y añade las siguientes imágenes:

```
img/
├── games/
│   ├── gtav-main.jpg          (Imagen principal para GTA V - hero section)
│   ├── gtav-1.jpg             (Exploración en Los Santos)
│   ├── gtav-2.jpg             (Conducción de coches)
│   ├── gtav-3.jpg             (Acción/Combate)
│
│   ├── fortnite-main.jpg       (Imagen principal para Fortnite)
│   ├── fortnite-1.jpg          (Combate/Batalla)
│   ├── fortnite-2.jpg          (Construcción)
│   ├── fortnite-3.jpg          (Personajes/Skins)
│
│   ├── fifa26-main.jpg         (Imagen principal para FIFA 26)
│   ├── fifa26-1.jpg            (Partidos/Estadios)
│   ├── fifa26-2.jpg            (Equipos/Formaciones)
│   ├── fifa26-3.jpg            (Jugadores)
│
│   ├── farcry6-main.jpg        (Imagen principal para Far Cry 6)
│   ├── farcry6-1.jpg           (Exploración de isla)
│   ├── farcry6-2.jpg           (Combate)
│   ├── farcry6-3.jpg           (Armamento/Armas)
│
│   ├── cod-main.jpg            (Imagen principal para Call of Duty)
│   ├── cod-1.jpg               (Multijugador)
│   ├── cod-2.jpg               (Campaña)
│   └── cod-3.jpg               (Modo Zombis)
```

## Especificaciones de Imagen

- **Formato**: JPG o PNG
- **Dimensiones Hero (main)**: 1920x1080px mínimo (ratio 16:9)
- **Dimensiones Galería**: 1024x576px mínimo (ratio 16:9)
- **Compresión**: Optimizadas para web (sin perder calidad)

## Descripción de Contenido para Cada Juego

### GTA V
- **Main**: Ciudad de Los Santos con rascacielos y tráfico
- **Galería**: Exploración urbana, coches deportivos, personajes principales

### Fortnite
- **Main**: Batalla real con construcciones coloridas
- **Galería**: Combates épicos, construcciones, skins populares

### FIFA 26
- **Main**: Estadio de fútbol con acción de partido
- **Galería**: Partidos intensos, equipos famosos, celebraciones

### Far Cry 6
- **Main**: Isla tropical de Yara, selva y acción
- **Galería**: Exploración de isla, combate intenso, armamento

### Call of Duty
- **Main**: Soldados en combate, acción intensa
- **Galería**: Multijugador épico, campaña cinematográfica, zombis

## Cómo Insertar las Imágenes

Simplemente coloca los archivos de imagen en la carpeta `img/games/` y los HTML las cargarán automáticamente desde las rutas ya configuradas.

**Nota**: Las páginas están configuradas para que funcionen sin imágenes (mostrarán espacios vacíos), pero se verán mucho mejor una vez añadas las imágenes reales.
